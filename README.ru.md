# VPN Pulse

**Работает ли мой VPN прямо сейчас — и к какому серверу подключаться?**

VPN Pulse — Telegram Mini App и бот для тех, кто держит несколько серверов WireGuard /
AmneziaWG (и при желании Xray) для друзей и родных. Он отвечает на один вопрос за три секунды —
по свидетельствам, а не по мнению самих серверов:

- 💻 **Проверка с компьютера** — настоящее VPN-подключение и HTTPS сквозь туннель изнутри страны,
  где живут ваши пользователи.
- 📶 **Проверка с телефона** — DNS оператора и доступность из мобильной сети, вне VPN.
- 🌍 **Перекрёстная проверка из-за границы** — серверы проверяют друг друга, поэтому «заблокирован
  в стране» и «сервер упал» перестают выглядеть одинаково.

Ноль подключённых людей — **не** поломка. Отсутствие данных показывается как *нет данных*,
а не как зелёные 100 %. Участники никогда не видят IP, домены, порты и хостера.

| Запись в SQLite: сессии, коды привязки, пробники, отчёты → наблюдения, заметка, аналитика, аудит, очистка по retention (`SqliteStore`); API не хранит состояние между запросами | работает |
| Цикл мониторинга `vpn-pulse run`: сбор → оценка → снимки → переходы → события → очередь уведомлений с повторами; ежечасная очистка; `--demo` проигрывает сценарии поверх настоящей базы | работает |
| CLI администратора: `vpn-pulse init / doctor / server add|list|remove / probe enroll|list|revoke / note set|clear|show`; `doctor` печатает следующие шаги экрана администратора, код выхода — как ворота; секреты `0600`, никогда не печатаются | работает |
| Установщик: `./install.sh demo` (вымышленные данные, без root и Telegram), `sudo ./install.sh install` (системный пользователь, venv на релиз, конфиг + секреты, юниты systemd, сниппет Caddy, doctor), `upgrade` с резервной копией и авто-откатом, `rollback`, `uninstall` с сохранением данных; проверено целиком на чистой Ubuntu 24.04 (`scripts/install_check.sh`) | работает |
| Gate A — вся локальная цепочка одним тестом: сценарный мир → цикл → SQLite → API → Mini App в браузере → Telegram Bot API на фейковом транспорте (`tests/test_e2e_gate_a.py`); Mini App отправляет разрешённую аналитику | зелёный |
| Read-only сборщики для реальных серверов (`server add` на стороне сервера), Telegram-бот в настоящей группе, пробники PC / Android / перекрёстные | **в планах** |

Установить на сервер можно уже сегодня и смотреть, как движутся вымышленные данные
(`--demo-data`); настоящие источники — сборщики на VPN-серверах и пробники — следующие
инкременты, поэтому настоящая установка до них показывает «нет данных».
См. [docs/quickstart.ru.md](docs/quickstart.ru.md).

## Две команды, чтобы увидеть

```bash
git clone https://github.com/MarkSinD/VPN-Pulse.git && cd VPN-Pulse
./install.sh demo                                 # Mini App + API на вымышленных данных: http://127.0.0.1:8765/app/mvp.html
sudo ./install.sh install --demo-data             # настоящая установка на Ubuntu 24.04 (юниты systemd, doctor); реальных данных пока нет
```

| Экран статуса (проблемы) | Экран сервера (тёмная тема) |

Каждый сервер — одна строка: кольцо-прибор с флагом показывает состояние (дуга — доступность за
24 часа), в строке — три источника проверки и график доступности. Нажатие открывает экран сервера.

## Пять минут для разработчика

```bash
git clone https://github.com/MarkSinD/VPN-Pulse.git
cd VPN-Pulse
python -m venv .venv && . .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
python -m pytest                                  # ядро бэкенда + контрактные тесты
python -m vpnpulse.dev                            # API на демо-сценариях + Mini App на /app/
python scripts/validate_specs.py                  # OpenAPI, схемы, паритет RU/EN
vpn-pulse run --demo --db demo.sqlite3            # цикл мониторинга на «сценарном мире» (Ctrl+C — стоп)
python -m vpnpulse.dev --sqlite demo.sqlite3      # …и Mini App, читающий эту базу вживую
```

Затем откройте `docs/prototypes/mvp.html` в браузере и переключайте в showcase-панели сценарии
(штатно, проблемы, недоступен, нет данных, офлайн, чистая установка, …), роль, тему и язык.

## Ограничения

- Ничто здесь не меняет ваш VPN. Сборщики только читают; приложение не выдаёт ключи.
- Обнаружение блокировки — вывод из независимых проверок, а не доказательство. Интерфейс говорит
  *«подключение не проходит из домашней сети»*, вероятную причину видит только администратор.
- Один компьютер-пробник покрывает одну сеть. Для других операторов нужны дополнительные пробники.
