# Brand

`logo.svg` — the mark: the pulse line of the app's own icon set (`web/src/icons.svg`, `i-pulse`) in the
operational green `#30d158`, stroke 2.8 on a 24-unit grid, round caps and joins. The build copies it to
`docs/prototypes/favicon.svg` (the page's icon); the README shows it; the header of the Mini App draws the
same path from the icon set in the theme's operational green (`#14713d` on light, `#30d158` on dark).
For a Telegram avatar render it on a `#1c1c1e` square, the mark inside the central 76 % (the avatar is
cropped to a circle).
